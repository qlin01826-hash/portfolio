李琬欣作品集｜GitHub Pages 静态版

打开方式
1. 先完整解压 ZIP，不要只在压缩包预览中打开。
2. 保持 index.html、assets、media 三者的相对位置不变。
3. 双击 index.html，推荐使用 Chrome、Edge 或 Safari。

说明
- 页面不需要登录、数据库或在线接口。
- 叶舟、学院迷雾、ArchEditor 的演示视频已经包含在 media 文件夹中。
- 探寻玛雅使用 YouTube 内嵌播放器，并保留外部跳转链接；该视频需要网络环境能够访问 YouTube。
- 项目导航和“查看更多”内容均在同一页面完成，不依赖线上路由。
- GitHub Pages 发布时，请将 index.html、.nojekyll、assets、media 放在仓库根目录。
