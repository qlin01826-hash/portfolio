试玩迭代

01

操作理解

问题 吐丝、收丝和物品处理键位分散，玩家需要反复记忆。

解决 将蛛丝操作集中到鼠标按键与滚轮，合并用途相近的物品操作。

02

探索动力

问题 环境安逸、生存压力偏低，玩家缺少前往目的地的动力。

解决 引入精神状态与河流污染，并用特殊物品提示故事背景。

03

玩家新用法

问题 玩家把持续刷新的叶片连成道路，削弱了航行必要性。

解决 区分叶片密集区与稀疏区，保留基地搭建，让跨区移动需要航行。

建造系统

规划 · 施工 · 区域

蓝图位于规划与施工之间；实际建成的结构和区域用途共同进入空间检查，再将能力交给养殖、员工、物流与安全系统。

查看建造系统细节规划 · 施工 · 区域 · 跨系统反馈

规划系统

从放置到蓝图

玩家选择目标与单件，查看占地、材料和前置条件，再调整位置、朝向并接受放置校验。通过后可暂存蓝图；确认开工才交给施工。

选择建造项目→查看依赖→占地与朝向预览→放置校验→蓝图 / 开工

实际建造

构件与施工

地基、墙、围栏、门、道路和设施是可组合对象。施工队列继续检查材料、员工与施工位；完工后分别更新外观、占地、通行和设施功能。

区域划分

用途与条件

区域读取已建墙、门与设施，检查围合、面积、入口和可达性。条件不足时列出缺口；结构或占地变化后重新检查。

跨系统影响

养殖与自动化

怪物长大 → 调整围栏与区域 → 检查投喂设施和员工路线 → 补充材料并开工 → 重新检查收容与照料条件。

建筑与区域→空间和设施状态→物流 / 员工 / 养殖→成本与产出→下一轮规划

AI 创作流程

体块 · 约束 · 生成

空间偏差返回 Unity 调整体块或视角；风格偏差返回文字提示与生成参数，让不同问题进入不同修改路径。

查看约束与修改判断空间输入 · 深度图 · 结果检查
空间约束

纯文字生成难以稳定保持建筑形体和空间关系。体块与深度图先明确空间边界，再交给生成模型。

修改路径

形体偏差返回 Unity；风格与表达偏差返回文字提示，避免把不同问题混在一次修改里。
